# PRD — Hands-Free Cooking Assistant

## 1. 제품 개요

### 제품명
Hands-Free Cooking Assistant

### 한 줄 소개
요리나 베이킹 중 손에 재료가 묻거나 젖어 스마트폰·태블릿을 직접 조작하기 어려운 상황에서, **손동작과 제스처만으로 레시피를 제어할 수 있는 AI 기반 비접촉 조리 보조 서비스

### 제품 목표
사용자가 조리 중 화면을 직접 터치하지 않고도 손동작을 이용하여 레시피의 다음 단계로 이동하고, 이전 단계로 돌아가거나 현재 단계를 다시 확인할 수 있도록 한다.

---

# 2. 문제 정의

요리나 베이킹을 할 때 레시피를 스마트폰이나 태블릿으로 확인하는 경우가 많다.

하지만 다음과 같은 상황에서는 화면을 직접 조작하기 어렵다.

- 반죽을 만들고 있어 손에 밀가루가 묻어 있는 경우
- 고기나 생선을 손질하고 있는 경우
- 물이나 기름 등으로 손이 젖어 있는 경우
- 장갑을 착용하고 있는 경우
- 조리 중 손을 씻고 다시 화면을 조작해야 하는 경우

특히 베이킹에서는 **반죽 상태를 유지하면서 레시피의 다음 단계로 이동해야 하는 상황**이 반복적으로 발생한다.

현재는 손을 씻거나 휴대폰을 직접 터치하거나 음성 명령을 사용해야 하기 때문에 조리 흐름이 끊기는 문제가 있다.

---

# 3. 해결 방법

카메라를 통해 사용자의 손동작을 실시간으로 인식하고, 특정 제스처를 레시피 조작 명령으로 변환한다.

### 기본 사용 흐름

레시피 실행
↓  
카메라가 사용자의 손동작 인식
↓
제스처 분류
↓
사용자가 설정한 명령 실행
↓
레시피 화면 변경

예:
| 손동작 | 기능 |
|---|---|
| 👋 손바닥 | 다음 단계 |
| ✊ 주먹 | 이전 단계 |
| ☝️ 검지 | 현재 단계 다시 보기 |
| ✌️ V | 레시피 전체 보기 |

※ 실제 개발 단계에서는 인식률과 오인식 가능성을 고려하여 2~3개의 제스처부터 MVP로 구현한다.

# 4. 핵심 사용자
### Primary User
요리 또는 베이킹을 하면서 스마트폰·태블릿으로 레시피를 확인하는 사용자.

특히 다음 사용자에게 유용하다.
- 베이킹을 자주 하는 사용자
- 레시피를 스마트폰으로 보면서 요리하는 사용자
- 손에 재료가 자주 묻는 사용자
- 조리 중 화면을 터치하는 것이 불편한 사용자

### 대표 사용자 시나리오
> 사용자가 베이킹을 하면서 반죽을 만들고 있다.  
> 손에는 밀가루와 버터가 묻어 있다.  
> 레시피를 다음 단계로 넘겨야 하지만 스마트폰을 터치하기 어렵다.  
> 사용자가 카메라에 손바닥을 보여준다.  
> 시스템이 이를 '다음 단계' 제스처로 인식한다.  
> 레시피가 자동으로 다음 단계로 이동한다.

# 5. MVP 범위
## 반드시 구현할 기능
### 5.1 레시피 표시

- 레시피 제목 표시
- 현재 단계 표시
- 단계별 설명 표시
- 이전/다음 단계 구분
- 현재 진행 단계 표시

### 5.2 손동작 인식

카메라를 통해 사용자의 손을 인식한다.

예:

- 손바닥 → 다음 단계
- 주먹 → 이전 단계
- 검지 → 현재 단계 재확인

### 5.3 제스처 → 명령 변환

인식된 손동작을 레시피 조작 명령으로 변환한다.

예:

`OPEN_PALM`

↓

`NEXT_STEP`

↓

다음 레시피 단계 표시

### 5.4 실행 결과 피드백

제스처가 정상적으로 인식되었는지 화면에 표시한다.

예:

> 👋 다음 단계

또는

> 다음 단계로 이동했습니다.

이를 통해 사용자가 자신의 제스처가 정상적으로 인식되었는지 확인할 수 있도록 한다.

# 6. AI / Computer Vision 기능

## 손동작 인식

카메라 영상에서 사용자의 손을 탐지하고 손가락의 위치 및 상태를 분석하여 제스처를 분류한다.

### 예상 처리 과정

Camera Input
↓
Hand Detection
↓
Hand Landmark 추출
↓
손가락 상태 분석
↓
Gesture Classification
↓
Command Mapping

예:
`손바닥`
→ 손가락 대부분 펼쳐짐
→ `OPEN_PALM`
→ `NEXT_STEP`

# 10. 사용자 경험 목표

사용자가 조리 중 **화면을 직접 만지지 않아도 레시피를 자연스럽게 조작**할 수 있어야 한다.

### 핵심 UX 원칙

1. 손동작은 단순해야 한다.
2. 카메라 앞에서 쉽게 인식되어야 한다.
3. 오인식으로 레시피가 갑자기 넘어가는 것을 방지해야 한다.
4. 인식 결과를 사용자에게 명확하게 알려야 한다.
5. 조리 흐름을 방해하지 않아야 한다.

---

# 11. 오인식 방지

조리 중에는 사용자의 손이 계속 움직이기 때문에 단순히 특정 손 모양을 한 프레임에서 발견했다고 바로 명령을 실행하면 오작동 가능성이 높다.

따라서 일정 시간 동안 동일한 제스처가 유지되는 경우에만 명령을 실행한다.

예:

**손바닥 인식**

↓

0.5~1초 이상 유지

↓

제스처 확정

↓

다음 단계 실행

또한 명령 실행 후에는 일정 시간 동안 같은 제스처를 무시하는 **Cooldown**을 적용한다.

# 14. 성공 지표

### 기능적 목표

- 손동작 인식 정확도 **90% 이상**
- 정상적인 제스처에 대한 명령 실행 성공률 **90% 이상**
- 제스처 인식 후 명령 실행 시간 **1초 이내**

### 사용자 경험 목표

테스트 사용자가 조리 중 화면을 직접 터치하지 않고 **레시피 5단계를 연속으로 제어할 수 있는지** 확인한다.

---

# 15. 핵심 차별점

기존 레시피 서비스의 핵심 기능은 **레시피를 제공하는 것**이다.

본 프로젝트는 레시피 자체보다 **조리 중 사용자가 레시피를 어떻게 조작하는가**에 초점을 맞춘다.

특히,

> **“손을 사용할 수 없는 상황에서 AI와 현실 세계 사이의 인터페이스를 제공한다.”**

는 점을 핵심 차별점으로 한다.

# 16. 프로젝트 핵심 가치

### 기존

조리 → 손에 재료가 묻음 → 스마트폰 터치 어려움 → 손 씻기 → 레시피 확인 → 다시 조리

### Hands-Free Cooking Assistant

조리 → 손에 재료가 묻음 → **손동작** → 레시피 확인 → 바로 조리 계속

즉, 사용자의 **조리 흐름을 끊지 않는 비접촉 AI 인터페이스**를 제공하는 것이 본 프로젝트의 핵심이다.

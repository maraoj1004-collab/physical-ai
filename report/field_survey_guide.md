[프로젝트]
나는 "Edge AI 기반 과일 수확 적기 판단 및 스마트 수확 보조 시스템"을 개발하고 있다.

시스템의 목표는 카메라로 과일을 촬영한 후 Edge Device에서 YOLO를 이용하여 과일을 탐지하고, 탐지된 과일 영역의 색상·크기·형태 특징을 분석하여 다음 3단계로 수확 상태를 판단하는 것이다.

- 수확 전
- 수확 적기
- 과숙

최종 시스템은 Raspberry Pi 기반 Edge AI 환경에서 실시간 또는 준실시간으로 동작시키는 것을 목표로 한다.

[분석 요청]

위 현장 조사 결과와 실제 이미지 데이터를 기반으로 내 환경에 가장 적합한 데이터 전처리 방법을 선정해줘.

단순히 일반적인 전처리 기법을 나열하지 말고, 반드시 "내 데이터에서 왜 필요한지"를 근거와 함께 설명해줘.

다음 항목을 순서대로 분석해줘.

1. 이미지 품질 전처리
- Blur Detection
- Noise Reduction
- 과노출/저노출 처리
- 이미지 필터링
- 필요한 경우 구체적인 기준값 제안

2. 이미지 크기 전처리
- Resize
- Letterbox
- YOLO 입력 해상도
- 적절한 입력 크기 선정 근거

3. 조명 전처리
- Brightness Normalization
- Gamma Correction
- CLAHE
- Contrast Adjustment

각 방법을 적용해야 하는지, 적용하지 않는 것이 좋은지를 데이터 특성에 따라 판단해줘.

4. 색상 전처리
- RGB
- HSV
- Lab

내 과일의 숙도 판단에 어떤 색공간이 가장 적합한지 비교해줘.

특히 색상이 숙도 판단의 핵심 특징이므로 색상 정보를 지나치게 변형하는 전처리는 피해야 하는지도 판단해줘.

5. YOLO 객체 탐지 전처리
- Resize / Letterbox
- Normalization
- Mosaic
- Scale
- Rotation
- Translation
- Blur
- Noise
- Occlusion augmentation

각 방법의 적용 여부와 권장 수준을 제안해줘.

6. 과일 Crop 및 배경 제거
- Bounding Box Crop
- Crop Padding
- Masking
- Background Removal

잎, 가지, 토양 등이 색상 분석에 미치는 영향을 고려하여 가장 적합한 방법을 선정해줘.

7. 숙도 판단용 특징 추출
다음 특징 중 실제 데이터에 필요한 것을 선정해줘.

- Hue
- Saturation
- Value
- Lab L/a/b
- Color Histogram
- 과일 면적
- Bounding Box 크기
- Aspect Ratio
- Contour
- Circularity

8. 데이터 증강
실제 현장 환경을 고려하여 필요한 증강만 선정해줘.

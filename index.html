HOW IT WORKS

카메라에서 LED까지,
모든 판단이 현장에서 끝납니다.

  1. 01 photo_camera

    영상 입력

  2. 02 center_focus_strong

    과일 탐지

    YOLO 모델이 과일마다 Bounding Box를 만듭니다.

  3. 03 palette

    색상·크기 분석

    수확 적기 판단

  5. 05 emoji_objects

    화면 + LED 출력

    MQTT/WebSocket으로 결과를 보내고 GPIO로 LED를 켭니다.

WHY EDGE AI

왜 클라우드가 아니라 Edge일까요?

과수원은 통신이 약하고, 수확 판단은 즉시 이뤄져야 합니다. 그래서 추론을 현장의 기기에서 직접 수행합니다.

cloudCloud 방식

Camera → Network → Cloud Server → AI 추론 → Network → Result

  • 네트워크 왕복으로 지연 발생
  • 통신이 끊기면 사용 불가
  • 영상 데이터를 외부로 전송

memoryEdge 방식 (HarvestEdge)

Camera → Raspberry Pi → AI 추론 → Result

  • 현장에서 즉시 판단
  • 오프라인에서도 동작
  • 영상이 기기 밖으로 나가지 않음

science POC에서는 같은 입력 영상으로 Cloud와 Edge의 Latency와 FPS를 직접 측정하여, 주장 대신 실제 수치로 Edge AI의 효과를 검증합니다.
